## 3. Social Preview Image

The OpenGraph / Twitter card image is located at:
- File path: [`docs/img/social-preview.png`](img/social-preview.png)
- Dimensions: 1280 × 640 px (standard 2:1 GitHub social card ratio)
- Content: Dark theme card with Sentinel shield icon, headline, key badges (99.7% Precision, 0 FP on 930 Repos, CycloneDX SBOM, Sigstore Signed).

To set in GitHub:
1. Navigate to **Settings** > **General**.
2. Scroll to **Social preview**.
3. Click **Edit** > **Upload an image** > select `docs/img/social-preview.png`.
