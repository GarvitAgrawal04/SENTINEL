# Sentinel SARIF 2.1.0 Specification

Sentinel natively exports Static Analysis Results Format (SARIF) version 2.1.0 documents across all scanning interfaces:
- `sentinel scan <target> --format sarif`
- `sentinel scan --machine --yes --format sarif`
- `sentinel pr --base <ref> --format sarif`
- `sentinel doctor <target> --format sarif`

SARIF files generated by Sentinel comply with the OASIS SARIF 2.1.0 standard and integrate directly with GitHub Code Scanning (the "Security" tab on GitHub repositories).

## Schema & Driver Identity

- **Schema URI:** `https://raw.githubusercontent.com/oasis-tcs/sarif-spec/master/Schemata/sarif-schema-2.1.0.json`
- **SARIF Version:** `2.1.0`
- **Driver Name:** `Sentinel`
- **Information URI:** `https://github.com/GarvitAgrawal04/SENTINEL`

## Severity Mapping

Findings are mapped to standard SARIF result levels:

| Sentinel Severity | Conditions | SARIF `level` | GitHub Security Badge |
|:---|:---|:---:|:---:|
| **Forced / Critical** | `forces_compromised: true`, penalty $\ge 35$ (`S1a`, `S5`, `S10`, `S18a`, `S18c`, `S21`, `S23`, `S26`, `D1`) | `error` | High / Error 🔴 |
| **Warning / Suspicious** | `ceiling: true`, penalty between 15 and 34 (`S1b`, `S2`, `S4`, `S6`, `S14b`, `S17a`, `S18b`, `S19`, `S20`) | `warning` | Warning 🟡 |
| **Observation / Advisory** | Informational findings, `D2`, `SEM01`, zero-penalty observations | `note` | Info / Note 🔵 |

## Physical Locations & Line Mapping

Each result records a single physical location within `locations[0].physicalLocation`:
- `artifactLocation.uri`: Repository-relative POSIX path (forward slashes) matching repository source trees.
- `region.startLine`: 1-indexed source line where the offending instruction or configuration key resides.
- `region.startColumn`: 1.

## GitHub Actions Code Scanning Snippet

To upload Sentinel SARIF results to the GitHub Security tab:

```yaml
name: Sentinel Security Scan

on:
  push:
    branches: [main]
  pull_request:

jobs:
  scan:
    runs-on: ubuntu-latest
    permissions:
      contents: read
      security-events: write

    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"

      - name: Install Sentinel
        run: pip install sentinel-md

      - name: Run Sentinel Scan
        run: sentinel scan . --format sarif > sentinel.sarif

      - name: Upload to GitHub Code Scanning
        if: always()
        uses: github/codeql-action/upload-sarif@v3
        with:
          sarif_file: sentinel.sarif
          category: sentinel-agent-security
```
