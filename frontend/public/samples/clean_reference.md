# Project Instructions for AI Coding Agents

This file provides context for AI coding assistants working in this repository.

## Code Style
- Use TypeScript for all new files
- Prefer functional components in React
- Run `npm test` before committing

## Architecture Notes
This project uses a standard REST API backend with a React frontend.
See docs/architecture.md for the full system diagram.

## Testing
Run the full test suite with `npm run test:all`. Integration tests
require a local Postgres instance — see docs/setup.md.
